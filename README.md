Тестовое задание для AQA стажёра в компании учи

## Подготовка к работе

Нужны [Node.js и npm](https://nodejs.org/en/download) и установленный Google Chrome.
Тесты гоняются в системном Chrome: встроенный Chromium Playwright не загружает виджет поддержки.

Установите зависимости:

```shell
npm ci
```

## Запуск тестов

```shell
npx playwright test
```

## Что проверяют тесты

Это e2e-тесты виджета «Помощь» на главной [https://uchi.ru](https://uchi.ru).
Браузер открывает сайт и кликает по виджету, как пользователь.

- `opens` — виджет открывается. Был в исходном репозитории.
- `has correct title` — первая популярная статья, кнопка «Написать нам», в шапке текст «Связь с поддержкой». Был в исходном репозитории.
- `closes` — виджет закрывается крестиком. Самостоятельно написанный тест.

## Что изменено

Исходные два теста падали. Селекторы и порядок действий поправлены под текущую главную.

- Запуск переведён на системный Chrome (`channel: 'chrome'` в `playwright.config.ts`).
- Перед открытием страницы ставится кука `ab_mainpage_redesign=a`, иначе главная иногда открывается в редизайне без виджета.
- Страница открывается по `domcontentloaded`: полное событие `load` на uchi.ru часто не наступает.
- Баннер cookie закрывается по видимой кнопке «ОК». Таких кнопок на странице две, и баннер появляется не сразу.
- Клик по «Помощь» ждёт, пока появится `window.supportWidget`. Иначе открывается пустая оболочка со спиннером и без статей.
- Список популярных статей не считывается заранее через `.all()`. Кликается первый элемент, когда он уже виден.
- «Написать нам» больше не ищется селектором `[class^=btn]`: под него попадали и кнопки оценки статьи. Теперь это кнопка с текстом «Написать нам».
- Заголовок проверяется через `toHaveText`, а не одним снимком `textContent()`.
- Крестик закрытия ищется как `button[class^=closeBtn]`. Рядом есть `div` с тем же префиксом класса. Этот селектор нужен добавленному тесту `closes`.
